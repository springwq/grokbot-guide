# 09 · 生活助理：购物、付款、订餐、订位、机票酒店、打车、退换货

[← 返回目录](../README.md)

Grok Bot 不只是办公工具。因为它有浏览器、能登录网站、能（在你批准下）付款，所以可以帮你处理大量生活事务。本章内容主要来自 App 内置的各场景工作说明。

> 🌏 说明：内置说明里点名的平台以欧美为主（Amazon、DoorDash、Uber 等）。对于其他地区的平台，Bot 同样可以用浏览器操作，但没有专门的「站点手册」时，顺畅程度可能不同。

## 0. 贯穿所有场景的三条规则

1. **你选、你批**：Bot 负责搜索、比较、加购物车、填表；**你选择商品并批准确切的订单**，批准才会下单。
2. **每笔购买单独批准**：即使设了预算、即使在预算内，每一单仍需你批准。拒绝就是最终答复，Bot 不会就同一笔再问。
3. **关键时刻截图**：购物车、结算页、确认页。

## 1. 付款方式

Bot 可以用以下方式付款，**任何一种都不会在你没批准的情况下扣款**：

| 方式 | 说明 |
|------|------|
| **X Money** | 用你的 X Money 卡付款；连接后为默认钱包。Bot 会等到商家最终确认页显示含税、运费、手续费的 **总价**，再弹出 **Approve / Cancel** 卡片，写明商品、商家和总价 |
| **Stripe Link** | 每笔购买生成一张 **一次性虚拟卡**，只用于一个商家的一笔订单，需要你授权 |
| **Shop Pay** | Shopify 商店走 Shop 自己的结账；其他网站发一张一次性 Shop 卡 |
| **你自己的银行卡** | 在结账页通过 **安全表单** 输入，卡号直接填进网页，Bot 看不到 |

- 没装钱包时，Bot 会问你一次要不要连接 X Money / Stripe Link / Shop Pay，或直接用你的卡。你说"用我的卡"它就不会再提钱包。
- 你把卡号直接打在聊天里也可以（会用于这次结账，不会复述），但 **只有在结账页通过安全表单输入的卡才会被安全保存**。
- 卡号、CVC、有效期、钱包发的虚拟卡信息 **只会输入到商家结账页**，不会出现在聊天、日志或发给任何人的消息里。
- 结账失败或超时后，Bot 会先核实订单是否其实已经成功（确认页、订单历史、邮件），再决定是否重试，避免重复下单。
- Bot 不会向你承诺退款、赔偿或保障；出问题时它会指向商家的退换政策、发卡行的争议流程或钱包的帮助页面，并可以帮你办退货。

### 预算与消费记录

```text
我每个月网购预算是 3 万日元，请记住。
```

- Bot 会把预算存进记忆；之后每次下单前会算本月已花多少，**如果这单会超预算，会告诉你超多少并先问你**。
- 每次下单后会记一笔：日期 | 商店 | 商品 | 总价 | 订单号。
- 问"这个月我在网上花了多少？"，它会逐笔列出并附订单号。

## 2. 购物

Bot 能理解的几种请求：

| 你说 | 它理解为 | 交付物 |
|------|---------|-------|
| "再买一次我常买的咖啡滤纸" | 复购 | 从订单历史开始，而不是重新搜索 |
| "买一台 65 寸电视，800 美元以内，评价要好" | 比较后购买（有预算） | 候选对比 → 你选 → 下单 |
| "帮我找一款好的旅行推车" | 浏览 | 一份候选清单，进购物车之前先给你看 |
| "这两款买哪个？""Target 是不是更便宜？" | 比较 | 并排对比，你来选 |
| "这个价格划算吗？要不要等降价？" | 购买建议 | 基于 **本次打开的价格历史和评价** 给出判断 |
| 发一个商品链接 | 直接去那个商品页 | — |
| 发一张商品照片 | 识别品牌型号后搜索 | 先和你确认是不是这件 |
| 一份清单 | 一个购物车多件商品 | 统一确认一次 |
| "帮我加购物车，我自己结账" | 只加购 | 填好购物车交给你，**不付款** |

## 3. 订单、物流、退换货、降价监控

- "有什么快递在路上？"——扫描你的订单/物流/退款邮件（需要邮件连接器）。
- "我的 Amazon 订单到哪了？"——查商店订单历史。
- 发快递单号或物流邮件——直接查承运商，无需登录商店（内置 UPS、USPS、FedEx 手册）。
- "那件夹克太大了，退掉"——退货，或换尺码。
- "取消我今早下的单"——只在发货前有效。
- "显示已送达但我没收到"/"到货是坏的"——问题申报。
- "降到 200 美元以下告诉我"/"到货通知我"——价格/库存监控（见 [第 4 章](04-routines.md) 价格监控示例）。
- "帮我盯这些商品的优惠"/"帮我领优惠券"——优惠监控。

**每一条状态、退款、工单进展都会附上来源邮件或页面链接**；没有来源就会直说，不会编造单号、物流节点或日期。任何改变订单或以你名义发出的东西都要你批准。

## 4. 订外卖

支持 DoorDash、Uber Eats、Grubhub，以及地区性平台（如 Deliveroo、Wolt、iFood、Just Eat），通过浏览器操作。

- 外送：**每次下单前都会和你确认送货地址**（即使网站已保存）；自取：确认门店和取餐时间。
- 下单前用问题卡片和你确认购物车摘要，你点"是"才会下单，而且下的就是卡片上读出的那个购物车。
- 你的口味、忌口、辣度、常去的店、小费规则可以存进记忆；过往订单留在平台上，Bot 去那里读。
- "随便帮我搞定晚饭"也行，它会根据你的偏好选。

```text
我饿了，帮我点一份晚饭外送到家，不要香菜，30 美元以内。下单前给我看购物车和地址。
```

## 5. 餐厅推荐与订位

- **推荐**：像一个懂本地美食、也懂你口味的朋友那样挑店——宁可少推几家真正值得去的。会参考本地评论家、美食指南和社区讨论（如城市的 Reddit 版块）。过敏、饮食禁忌、无障碍需求、预算上限是硬约束；口味偏好是软信号。
- **订位**：通过 OpenTable、Resy、Tock、TheFork、Yelp Reservations、餐厅官网或地区平台。Bot 会先查清这家店实际用哪个订位渠道（不会凭印象假设），读出所有可订时段、座位类型、定金或取消政策，**下订前和你确认**。

```text
周六晚上 7 点左右，4 个人，找一家适合庆生的日料，人均 1 万日元以内。先推荐 3 家，说明理由，我选好后你去订。
```

## 6. 机票

Grok Bot **没有自己的航班数据库**，所有价格和时刻都来自连接器、旅行网站（如 Google Flights、航空公司官网）或网页搜索，并会告诉你用的是哪个。

- 会先确定：出发地、目的地、日期、人数、舱位和硬约束（例如"会议前到达"、"不要红眼航班"）。
- "华盛顿"这类模糊地点会把 DCA、IAD、BWI 都查一遍并标明机场。
- 所有时间按 **当地机场时间**；跨时区时会标注每个时间对应的机场。
- 不会因为一次搜不到就说"没有航线"，会再用网页搜索核实。
- 还能办值机、取登机牌；转发确认邮件给它可以查行程、改签。
- 内置 United、Southwest、Google Flights、Expedia 手册。

```text
帮我查 12 月 20 日东京飞旧金山的直飞经济舱，1 个成人，按总价排序，列出航司、航班号、起降时间（标明机场时区）、行李规则。只查不订。
```

社区案例（The Aigentic 实测文章）：有人每周一让 Bot 重新检查一次行程价格，结果通过 Google Flights 找到比原方案便宜约 2,700 美元的东京行程。

## 7. 住宿

同样没有自己的房源库，数据来自 Airbnb（民宿）、Expedia（酒店）或酒店官网。

- 确定：目的地/街区、入住退房日期、人数（含儿童年龄）、总预算或每晚预算、硬约束（整套/单间、宠物、无障碍、停车、厨房、可免费取消）。
- 读出 **该日期该人数的真实总价**（含清洁费、服务费、税）、取消政策、最短入住、入住时段。
- 预订前确认。

## 8. 打车

支持 Uber、Lyft、Bolt、Grab 等。没有连接器时用网页版（Uber 用 `m.uber.com`，Lyft 用 `ride.lyft.com`）。网页版的车型和功能可能比手机 App 少。

- 确认 **上车点**（错一个点司机就去错门口）和目的地；家/公司等常用地址可以存进记忆。
- 立即叫车 vs 预约（"明早 7 点去机场"是预约）。
- 截图展示各车型、价格、接驾时间；**有高峰加价会明说**，并把「等一等」作为选项。
- **由你选车型并确认**，Bot 不会自己叫第一个选项。
- 结束时给你一条能找到车的信息。

## 9. 生鲜杂货

支持 Instacart、Costco Same-Day 等（"去趟 Costco"走的是 Costco Same-Day，而不是 costco.com 零售站）。

- "每周常规采购"：从记忆里的常购清单 + 网站的再次购买页开始。第一次没有清单时会先整理一份给你确认。
- "做 6 人份塔可需要的东西"：把菜谱转成清单并按份数放大，列出它省略的调味品让你补。
- 发清单或手写清单照片也行。
- 结账前确认送货地址；替换规则、品牌偏好、过敏信息存在记忆里。

## 10. 求职

- 来源：连接器、LinkedIn、公司招聘页或网页搜索，并注明来源。
- 先确定职位、地点/远程、级别、薪资底线、签证限制和不可接受条件（不 on-call、不搬家……）。
- 筛选后给你一份清单，**申请由你决定**：Bot 只用你提供过的事实填表，**绝不编造资历**。

## 11. 二手与市场

内置 Craigslist、Facebook Marketplace、eBay、Etsy 手册。官方博客作者的 Marketplace Bot 就在 Facebook Marketplace 和 Craigslist 上盯咖啡机，需要做判断时会去问他的「Chief of Staff」Bot。

```text
每天帮我看一次 Facebook Marketplace 和 Craigslist 上旧金山湾区的二手 Breville 咖啡机，200 美元以下、成色好的发给我，附链接和照片。不要联系卖家。
```
