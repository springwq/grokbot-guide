# 07 · Pages（页面 / Canvas）：Bot 为你做的「活文档」

[← 返回目录](../README.md)

> Pages 于 **2026-10-21** 开始逐步向所有用户推出（官方 @bot 账号："Grok Bot can now build reports, memos, and dashboards."）。暂不支持 Enterprise 团队。看不到的话，把桌面 App 更新到 **0.60.0+**、手机 App 更新到 **1.14.0+**。
> 社区和部分界面里也会把它叫作 *Canvas*（例如控制台里的 "Shared Canvases"）。

## 1. Page 是什么

Page 是 Bot 为你制作、供你阅读的东西：**报告、备忘录、看板（dashboard）、追踪表、讲解文档**……可以包含文字、表格、图表，以及筛选器、开关之类的控件。

和普通的聊天回答相比，Page 的特点是：

- **持续存在**：放在 Bot 的 **Library** 里，随时回来看；
- **持续更新**：你让 Bot 改，它就改同一份，所有能打开它的人看到的都是最新版本；
- **可以分享**：给团队，或生成公开链接。

## 2. 创建

直接在聊天里要：说明这个页面是干什么的、上面要有什么。

```text
做一个页面，对比这个邮件串里的三份报价，用表格列出价格、交付时间、付款条件，最后给一段简短建议。
```

Bot 做好后会在聊天里发一张卡片，显示页面标题和 **Open** 按钮。

## 3. 打开和修改

- **桌面端**：点卡片，页面占满窗口，聊天缩到旁边的小面板，可以边看边聊。
- **手机端**：点卡片在 App 内打开。
- **修改**：页面打开时，在旁边标着 **Message about <页面标题>** 的聊天面板里告诉 Bot 要改什么。Bot 更新后，之前的卡片会显示 **Updated below**，点它打开最新版。
- **页面上的筛选器和开关只改变你看到的视图，不会保存**。要改页面本身，请让 Bot 改。
- **重命名**：点击打开页面顶部的标题（仅限你创建的页面）。

## 4. 在哪里找

点对话顶部 Bot 名字 → **Library** 标签。这里列出该 Bot 做过的页面、文件和应用；已分享的页面会在行上标明。

每行右侧的 **⋯（More actions）**：**Open**、**Share…**、**Pin**（置顶到 **Pinned**）/ **Unpin**。

## 5. 分享

新页面默认 **只有你能看**。打开页面点顶部 **Share**（或 Library 里的 **Share…**），在 **Who can view** 中选择：

| 选项 | 谁能打开 |
|------|---------|
| **People you invite**（个人账号显示为 **Only you**） | 你和你添加的同事/组，均为 Viewer |
| **Your team**（或团队名） | Cursor 团队所有人 |
| **Anyone with the link** | 任何人，无需登录 |

然后 **Copy link** 发出去。

- 团队链接或邀请链接需要对方先用 Cursor 账号登录。
- 所有被分享者都能阅读页面、使用控件，但 **只有 Bot 能修改页面**。
- 选「任何人可访问」时，页面会获得一个 `pages.grok.bot` 下的网址（由标题生成；之后改名网址不变；暂不能自定义）。**页面里有任何私密信息就不要公开分享。**
- 个人账号的页面不能「团队分享」；Enterprise 团队关闭了公开分享。
- 查看和管理所有分享过的页面：Cursor 控制台的 **Shared Canvases**（<https://cursor.com/dashboard/shared-canvases>）→ **Grok Bot Pages**，可改权限或删除（删除后持链接者无法再访问）。

## 6. 好用的页面点子

来自官方说明和社区早期用法：

- **每日状态页**：社区里有人认为这是大多数人应该做的第一个页面（X 用户 @MaxSobol）。
- **Bot 管理看板**：追踪自己所有 Bot 的忙碌 / 阻塞 / 空闲状态（X 用户 @ashnichrist）。
- **X 帖子表现看板**：每条帖子相对中位数的表现。
- **报价/方案对比页**、**旅行行程页**、**本周指标页**。
- **结合例程**：让例程每天早上更新同一个页面，而不是每天发一大段消息。

```text
做一个「本周指标」页面：从 <数据来源> 拉取每日活跃用户、新注册、付费转化，用折线图展示最近 4 周，顶部放 3 个关键数字。
然后设一个例程，每个工作日早上 9 点刷新这个页面，只有数据出现异常（比上周同期波动超过 20%）时才在聊天里提醒我。
```

```text
做一个我下周东京—大阪出差的行程页面：按天列出交通、酒店、会议，每项附确认号和链接。之后有变化你就更新这个页面。
```

## 7. 注意

- 页面是 Bot 生成的，**重要数字请让 Bot 附上来源链接**，并在决策前让它重新拉取最新数据。
- 公开链接无需登录即可访问，等同于发布到互联网。
